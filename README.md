# Sprite Tracker (unofficial)

A free, fan-made checklist for tracking which Sprites you have collected and which you still need.

- `index.html` is the whole app.
- `sprites.json` is the sprite list. Edit this file to add new sprites; the app picks it up on next open.
- Marks are saved on each person's own device.
